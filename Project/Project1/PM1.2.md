# Project Milestone 1.2: Design

This project milestone will focus on the design of your system.

### High-level Design

Describe which architectural pattern you would use to structure the system. Justify your answer.

### Low-level Design

Discuss which design pattern family might be helpful for implementing a specific subtask for this project. Justify your answer, providing a code or pseudocode representation _and_ an informal class diagram.

### Prototype

Provide a visual overview of the look and feel of your project. This may include but is not limited to one of the following:

* wireframe mockup of your project user interface in action.
* storyboard that illustrates a primary task that a user would complete with your project.
* interactive digital prototype using tools such as Canva, Figma, etc.
* preliminary implementation of the system design (i.e., already implemented in code)

Provide a brief rationale (no more than 1 paragraph) explaining some of the design decisions for your program based on the provided sketch. Also discuss which of the usability heuristics played a role in the UI design of your system. Which ones might your proposed design lack?

### Usability Testing

Design a task for users to complete with the prototype developed above. The task should represent a real-world workflow of your system or consist of relevant questions to pose to potential users. Collect feedback on the prototype from at least **_5_** participants, ideally representing the target user base. Include the task(s) users completed and the raw results for this submission. A more detailed analysis of the results will be submitted with the final report.
