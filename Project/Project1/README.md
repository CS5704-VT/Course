# Project 1

Software has a major impact on the entire world and in nearly every area of our lives. Software engineering is a complex activity, involving numerous sources of complexity and coordination to develop and maintain high quality software. To that end, the goal for this CS5704 project will be to develop a software system. For your project, you will utilize methods and tools for software development life cycle phases (mostly `requirements` and `design`) discussed in class.


**Learning Outcomes:**
> * Implement a software system following the software life cycle phases
> * Develop software engineering skills working on a team project


The goal of this project is to practice software engineering processes, tools, and methods related to software requirements and design, and to gain practical experience working on a software project in a team setting.

## Guidelines

Your project must aim to solve a real-world problem. You are free to satisfy this goal however you wish. For this assignment, students:

* Must implement a software system;
* Must use a (public) GitHub repository;
* Must complete assigned requirements and design activities (Project Deliverables will be added to the Course Schedule);
* Must complete a demo presentation of the implemented system;
* May work in a group (choose your own team, or work individually);
* May use Generative AI tools to support implementation (adhering to the class and team-specific AI policy).

### Teams

If you work in a team, work must be equally divided among the team members. All groups will construct a team policy outlining team meeting preferences, AI usage, etc. Each member of the team must adhere to this policy for the duration of the project.

### Technology

All projects should be maintained in a public [GitHub](https://github.com) repository. To track work, teams should utilize task management (i.e. GitHub projects) and/or issue tracking (i.e. GitHub issues) on GitHub.
