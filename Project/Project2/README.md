# Project 2

Modern software engineering is largely about maintaining and evolving existing software systems. To this end, Project 2 will focus on maintaining and extending an existing software application. Participants will gain hands-on experience in the vital task of software maintenance, which includes adding new features, fixing bugs, testing, and optimizing performance. Maintaining software is a fundamental skill for software development. Through this project, you will learn to navigate real-world challenges such as understanding an unfamiliar codebase, collaborating with team members, configuring systems, and ensuring that updates do not disrupt existing functionalities. 

**Learning Outcomes:**
> * Implement a software system following the software life cycle phases
> * Develop software engineering skills working on a team project

The goal of this project is to practice software engineering processes, tools, and methods related to software implementation, maintenance, and testing to gain practical experience working on a software project in a team setting.

## Guidelines

In this project, you will take on the role of maintaining and extending an application developed by another team during Project 1. You will be expected to make consistent updates to your codebase across three two-week sprints. For this assignment, students:

* Must understand and analyze an existing codebase;
* Must track work in progress and planned tasks in a GitHub project and/or GitHub issues;
* Must implement at least two enhancements to the codebase (e.g., new feature or bug fix---one from the original team, one proposed by the Project 2 team);
* Must complete assigned maintenance and testing activities (Project Deliverables will be added to the Course Schedule);
* Must complete a demo presentation of the updated system;
* Must work in an assigned group;
* May use Generative AI tools to support implementation and maintenance (adhering to the class and team-specific AI policies).

### Teams

You will be assigned a team to work on for Project 2. Working in a team is required, and work must be equally divided among the team members. All groups will construct a team policy outlining team meeting preferences, AI usage, etc. Each member of the team must adhere to this policy for the duration of the project.

### Technology

All projects will be maintained on [GitHub](https://github.com). You must create a fork of the original project repository for your development efforts.
